# shantanusomwanshi.com

Personal site for Shantanu Somwanshi — instrumentation engineer, CFA Level I
candidate, and writer of a personal finance/investing newsletter. Vite +
React 19 + Tailwind CSS v4 + Framer Motion + Recharts + lucide-react, no
backend, no CMS. Deployed as a static build (see README for dev/build
commands).

## Voice and content rules

- **Every number on this site is real**, pulled from the newsletter's actual
  Python analysis or the live Substack post. Never invent figures, quotes,
  or newsletter body copy to fill a gap — ask for the real text/data or
  leave a clearly-marked placeholder instead.
- The newsletter is a **personal finance / investing** newsletter, not
  narrowly a "compounding newsletter" — compounding is one recurring theme
  (and the current issue's topic), not the whole scope. Keep site copy
  ("what I do", hero, footer) framed broadly.
- Copy across the site is terse, first-person, no marketing fluff. Match
  the existing tone rather than writing generic portfolio-site copy.

## Structure

- `src/components/Hero.jsx` — the trace animation (flat signal → sharp
  bend), the one big motion moment. Path generated by `src/lib/tracePath.js`
  (deterministic, no `Math.random`).
- `src/components/WhatIDo.jsx` — instrumentation / newsletter / software,
  three short blocks.
- `src/components/Newsletter.jsx` + `IssueCard.jsx` — newsletter issue
  cards with a live Recharts mini-chart per issue, code-split from the main
  bundle (`Newsletter` chunk).
- `src/components/IssueModal.jsx` — the full-issue reader, opened from
  `IssueCard`. Renders `issue.content` blocks (see schema below) in a
  Substack-like layout (byline → serif title → italic subtitle → body).
  Chart images inside the reader are clickable and open in a `Lightbox`
  (same file) — full-size, Escape/backdrop-click to close, independent of
  the reader modal's own Escape handler.
- `src/components/Work.jsx` — projects.
- `src/components/Footer.jsx` — contact.
- `src/data/newsletter.js` — newsletter issues, see schema below.
- `src/data/projects.js` — project list.
- `src/data/links.js` — shared profile links (GitHub, LinkedIn, newsletter,
  email).
- `public/newsletter/` — static chart images (PNG) embedded in issue
  content blocks, copied from the newsletter repo's `Code/` output at
  publish time.

## Newsletter data schema (`src/data/newsletter.js`)

Each entry in `issues` needs: `id`, `number`, `title`, `hook` (subtitle),
`date`, `substackUrl`, `githubUrl`, `stats` (4 card callouts), `chart`
(sampled series for the card's mini-chart), and `content` — the full issue
body rendered by `IssueModal`.

`content` is an array of blocks:
- `{ type: "p", text }` — paragraph. `text` supports inline `**bold**` and
  `*italic*` (parsed by `renderInline` in `IssueModal.jsx`).
- `{ type: "h2", text }` — subheading.
- `{ type: "quote", text }` — pull quote.
- `{ type: "list", items: [...] }` — bullets, same inline formatting.
- `{ type: "image", src, alt, caption }` — chart image. `src` is an
  absolute path into `public/newsletter/`. Clicking it opens the lightbox.

**To add a new issue**: transcribe the real Substack post text/captions
into a new `content` array (don't paraphrase or summarize — this is meant
to read exactly like the published issue), drop any chart PNGs into
`public/newsletter/`, and push a new object into `issues` with the shape
above. No component changes needed.

## Styling conventions

Theme tokens live in `src/index.css` under `@theme` — always use these
instead of hardcoding colors:

- `--color-bg` (near-black), `--color-paper` (off-white text),
  `--color-accent` (amber), `--color-teal`, `--color-line` (hairline
  borders, used via the `.hr-line` utility class), `--color-ink`.
- `--font-display` (Fraunces, headings), `--font-body` (Source Serif 4,
  default body — already Substack-like serif), `--font-mono` (IBM Plex
  Mono, labels/eyebrows/metadata).

Motion: `framer-motion`, gated by `useReducedMotion()` everywhere —
`initial={reduceMotion ? false : {...}}` is the standard pattern. Section
reveals use `whileInView` with `viewport={{ once: true, margin: "-80px" }}`.
